❓ คำถามที่พบบ่อย

The ASEAN Grid คืออะไร?

โปรเจกต์โอเพนซอร์สที่รวบรวมพลังการ์ดจอว่างของเกมเมอร์และร้านอินเทอร์เน็ตคาเฟ่ทั่วอาเซียน (เช่น RTX 4090, RTX 4070 Ti Super) กลายเป็นเครือข่ายซูเปอร์คอมพิวเตอร์กระจายศูนย์ รับงาน AI / เรนเดอร์ / Cloud Gaming จากทั่วโลก ผ่านโมเดลธุรกิจ SaaS + ระบบเติมเงินสไตล์ API Key

การ์ดจอของฉันปล่อยเช่าได้เดือนละเท่าไหร่?

ขึ้นอยู่กับรุ่นการ์ดจอและชั่วโมงว่าง เช่น RTX 4090 ที่ว่าง 12 ชั่วโมงต่อวันมีรายได้ประมาณ 150-300 บาทต่อวัน คำนวณได้ฟรีจากเครื่องคำนวณรายได้ GPU ด้านบน
