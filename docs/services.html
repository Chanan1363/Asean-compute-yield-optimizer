💡 เราให้บริการอะไร / What we offer

ASEAN Grid คือ เครือข่ายพลังคำนวณ GPU แบบกระจายศูนย์ในอาเซียน — รวบรวมการ์ดจอที่ว่างของเกมเมอร์/ร้านอินเทอร์เน็ตคาเฟ่/ผู้ใช้ทั่วไป กลายเป็น "โรงไฟฟ้าดิจิทัล" ที่รับงาน AI จากทั่วโลก ด้วยราคาที่ถูกกว่าคลาวด์ยักษ์หลายเท่า

We pool idle GPUs across Southeast Asia into a decentralized compute grid serving global AI demand — at a fraction of hyperscale cloud prices.

🧩 บริการหลัก / Core services

บริการเหมาะกับใครราคา
AI Inference — รันโมเดล AI (แชทบอท, OCR, แปลภาษา, ประมวลเอกสาร)สตาร์ทอัพ AI, ธุรกิจท้องถิ่น, นักพัฒนาถูกกว่าคลาวด์ยักษ์ 10-20 เท่า
AI Fine-tuning — ปรับโมเดลให้เฉพาะงาน (LoRA/QLoRA)มหาวิทยาลัย, นักวิจัย, บริษัท AIจ่ายวินาทีต่อวินาที
3D Rendering — เรนเดอร์ภาพ/วิดีโอ/VFXสตูดิโอ, นักออกแบบ, บริษัทเกมไม่มีขั้นต่ำ จ่ายเท่าที่ใช้
Cloud Gaming (เร็วๆ นี้) — เรนเดอร์เกมบนคลาวด์ผู้ให้บริการเกม, สตรีมเมอร์ตามแผนธุรกิจ

ทุกบริการใช้พลังจากเครือข่ายเดียวกัน — สมอง Arbitrage Engine คัดสรรช่องทางที่จ่ายดีที่สุดให้อัตโนมัติทุกวินาที

💳 ระบบคิดเงินที่เป็นธรรม / Fair billing

  • จ่ายวินาทีต่อวินาที (Pay-per-Compute) — ไม่ทำงาน = ไม่จ่าย ไม่มีค่าใช้จ่ายแฝง
  • เติมเงินล่วงหน้า (Prepaid API Key) — เหมาะกับองค์กร ควบคุมงบประมาณได้
  • รับชำระทั้ง USD และ Crypto (USDT) — จ่ายง่ายจากทุกประเทศ
  • จ่ายรายวันให้เจ้าของเครื่อง 75% — รายได้เข้าบาทไทยได้ (Local THB Exchange)

สัดส่วนรายได้โปร่งใส: 75% เจ้าของเครื่อง / 20% ค่าดูแลระบบ / 5% กองทุนนักพัฒนา — ตรวจสอบได้จากสมาร์ทคอนแทร็กต์
